AI & ML SET 2 - EXPERIMENTS 4(a) THROUGH 6(b)

Install packages:
    pip install numpy pandas matplotlib scikit-learn

Run one of the six individual scripts:
    python 4a_KNN_Classifier.py
    python 4b_State_Based_Agent.py
    python 5a_Naive_Bayes.py
    python 5b_Uniform_Cost_Search.py
    python 6a_K_Means.py
    python 6b_Supervised_Logistic_Regression.py

Or use the combined menu script:
    python AI_ML_Set_2_All_Experiments.py

Run a particular experiment from the combined script:
    python AI_ML_Set_2_All_Experiments.py 5b

KNN dataset:
    For the lab record's original data, place purchase_dataset.csv in the
    same folder as the .py script with the age, salary and target in columns
    3, 4 and 5. The file was not included with the PDF. Without it, the
    script generates a sample dataset and prints that it did so.

These are shortened executable versions of the six experiments, preserving
key code outputs and relevant plots. 6(b) uses Logistic Regression as the
supervised learning case study.
